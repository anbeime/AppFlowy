# 龙虾市场 · Lobster Market v1

海鲜经营游戏 + 真实营养学教育。从一盆小龙虾起步，把摊子做成整个海鲜市场。
（专题：`research_projects.id = 74/75` 龙虾市场游戏开发专题）

## 运行

双击 `index.html` 即可（纯静态、零依赖、无构建）。浏览器建议 Chrome / Edge。
需要联网？**不需要** —— 所有数据与逻辑都在本地，断网可玩。

## 技术范式（沿用 Odyssey Lite）

## 玩法

1. 顾客上门，说出真实营养诉求（如「医生说要补 DHA，但汞千万不能高」）。
2. 从货架选一样海鲜（点击卡片或按 `1-9`）；想看某海鲜的详细营养，点卡片右上角的「!」（弹雷达图 + 汞条 + 可持续标识）。
3. 选做法：`Q` 清蒸 / `W` 蒜蓉 / `E` 油焖 / `R` 麻辣 —— **利润越高，健康值扣分越多**。
4. 结算面板给出可核对依据：需求满足情况、FDA/EPA 汞判定、海洋守护者积分。
5. 金币达标解锁下一阶段：①虾蟹贝 → ②白色鱼 → ③多脂鱼 → ④深海（**解锁时强制弹汞警告**）。
6. `T` 打开营养图鉴：五维雷达图（蛋白/Omega-3/锌/硒/B12）+ 汞含量条 + 营养师点评 + 数据来源 + **集齐阶段奖励**。

**v1.1 新内容（D-LOB-02）**
- **顾客队列**：同时有 2-3 位顾客在等，每位都有独立倒计时与情绪（😊→😐→😣→😡），等待越久越不耐烦，超时直接走人扣声望。
- **回头客**：曾满意离店的顾客有概率作为「🎀回头客」再来，小费 +20%。
- **队列优先级**：点击排队中的顾客、或按 `[` `]` 可把他提到最前优先服务。
- **汞科普平衡文案（消除恐吓式科普）**：高汞鱼被拒收时，结算理由会补一句「低汞鱼每周 2-3 份仍被 FDA 推荐，Omega-3 收益远大于风险」，只在 ≥0.5ppm 鱼种上触发惩罚；图鉴首页也加了总纲。
- **图鉴收集奖励**：集齐某一阶段全部海鲜 → 获得称号（如「虾蟹贝通」）且该阶段海鲜收入 +10%。
- **儿童汞阈值放宽 0.10 → 0.15ppm**：此前会把低汞的鳕鱼（0.11）误判拒收，现已修正（FDA 把鳕鱼列在 Best Choices）。

**v1.2 新内容（D-LOB-01 · 移动端适配）**
- **虚拟按键条**：画布下方常驻 📖图鉴 / 🔊音效 / ➡️下一位 / 🔄重置 四个按钮，无键盘也能完整操作。
- **统一指针事件**：用 `pointerdown` 取代 `click`，同时覆盖鼠标 / 触屏 / 手写笔，去掉移动端 300ms 点击延迟；`touch-action:none` + 禁双击缩放 + 禁文本选中。
- **DPR 感知的真实分辨率渲染（修复移动端文字糊成一团）**：画布缓冲区 = CSS 尺寸 × `devicePixelRatio`，再以统一缩放 `U = vw/1280` 绘制设计坐标。**不再把 1280×720 位图缩小**，中文在手机/高分屏上清晰不叠加。横屏手机整屏放下 16:9 画面；竖屏也可直接玩（画面等比缩小到屏宽）。
- **键盘仍保留**：桌面端 `1-9` / `QWER` / `T` / `空格` / `M` / `N` / `[` `]` 全部可用。

触屏主路径：点货架选海鲜 → 点做法出餐 → 点「下一位」继续；点排队顾客可优先服务。

**v1.3 新内容（UX：以图案为主，详情收进「!」）**
- **货架改为图案优先**：卡片只显示大 emoji + 名称 + 价格，不再内联数值文字（蛋白/ω3/锌/汞/判定）。
- **「!」营养详情弹层**：每张解锁卡片右上角有一个按汞风险着色的「!」角标（绿=低汞 / 橙=中等 / 红=高汞）。点它弹出详情：**五维雷达图 + 汞含量条 + 可持续标识 + 营养师点评**，点空白处或「✕」关闭（键盘 `Esc` 亦可）。把「太详细的信息」从主画面移走，主游戏更干净。
- **修复竖屏真 bug**：竖屏下「排队区」与「做法栏」几何重叠，原会导致点做法时点中排队（cook 阶段 promote 无效）而出不了餐；现排队命中区仅在 serve 阶段激活。
- 横竖屏两套布局均支持「!」详情与图案优先货架。

**v1.5 新内容（UX：尽量用图像不用文字）**
- **系统性去文字化**：把结构性文字（标签、说明、列表）替换为 emoji 图标 + 数字 + 图形进度条，主画面以图案为主。
  - HUD：阶段改 `🦐/🐟/🍣/🗡️ Lv.n` 图标；下一档进度改 `💰 当前/目标`；全解锁改 `🏆 全解锁`。
  - 货架标题 `🏪 货架`、价格 `💰N`；做法栏 `「名」🍳` + `❤️健康 💰×倍率`；队列 `👥 队列·点我优先` + `#n ns` 倒计时。
  - 页脚图标行：`🏪选货 ❗营养 🍳做法 👥优先 📖图鉴`；结算 extra 图标行 `💰+N ❤️N 🌊N`(+🎀)。
  - 图鉴：维度图标化（`💪🧠🛡️⚡🩸☀️🍃`）、汞 `☢️ 汞`、可持续性 `🏅/🚫/🐟`；结算理由前缀语义图标（`✅❌⚠️💰🏅🌊🚫`）。
- **新增首屏图标化引导层 `drawIntro`**：首次进入以图案直接教会玩法——🦞龙虾市场、顾客气泡=他要什么、🏪→🍳→😋 流程、❗红点看营养、🔴高汞警示、💰解锁；底部 `▶ 开始游戏`。状态持久化 localStorage（`seenIntro`，不再重复弹）。
- 顾客需求关键词与营养数值仍保留在气泡/「!」详情/图鉴内（属深入信息），主画面只放图案与关键数字。


## 教育设计（不是装饰，是记分规则）

- **营养知识 = 分数**：选对才拿小费，选错只拿六折，违反限制直接拒收 + 声望 -1。
- **汞是硬约束**：孕妇 / 儿童顾客有汞上限，卖旗鱼（1.00ppm）会被当场拒收。数据来源 FDA/EPA 官方鱼种汞表。
- **做法改变结论**：麻辣赚 25% 溢价但健康 -2，清蒸健康 +2 —— 引导「清蒸才是正确打开方式」。
- **可持续性有正负反馈**：MSC/ASC 认证 +2 海洋守护者积分，过度捕捞鱼种 -3。
- **星级奖励结构而非规模**：只卖虾蟹贝永远 1 星；按需求文档 §三.3，经营贝类 + 多脂鱼即解锁 5 星（无需叠加认证门槛）。
